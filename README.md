# 👕 Controle de Camisas - MVP

Este é um sistema desenvolvido em Python focado na automação e gerenciamento do controle de camisas (como listagem de tamanhos, pedidos e status de pendências). O objetivo principal é transformar processos manuais de planilhas em uma análise automatizada, rápida e livre de erros humanos.

---

## 🚀 Funcionalidades Atuais (MVP)

* **Análise Automatizada:** Cruzamento de dados de pedidos e entregas.
* **Filtro de Pendências:** Identificação rápida de quem ainda falta receber ou pagar.
* **Segurança de Dados:** Arquivo de configuração que impede a exposição de dados sensíveis de usuários/clientes na internet.

## 🛠️ Tecnologias Utilizadas

* **Python 3** (Lógica principal do sistema)
* **Pandas** (Para manipulação inteligente das planilhas Excel)
* **Git & GitHub** (Controle de versão e hospedagem do código)
